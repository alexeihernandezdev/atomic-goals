# Módulo: activity

Feed paginado de eventos de actividad (CREATED, UPDATED, COMPLETED, DELETED, RESTORED).

## Capas

- **domain/** — Entidades, value objects y errores del dominio
- **application/** — Use cases y puertos (gateways)
- **infrastructure/** — Implementaciones HTTP y mappers
- **presentation/** — Componentes, hooks, stores Zustand, schemas Zod
